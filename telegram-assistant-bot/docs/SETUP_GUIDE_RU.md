# Как запустить бота (просто, по шагам)

Это подробная инструкция «на пальцах». Ничего не нужно знать заранее —
просто выполняй шаги по порядку, копируя команды.

Тебе понадобится компьютер (Windows, Mac или Linux) и 15–20 минут.

---

## Что вообще произойдёт

1. Ты создашь своего личного робота в Telegram (это делает специальный бот
   @BotFather — он выдаёт «пароль» для твоего робота).
2. Ты получишь ключ у OpenAI — это как «пропуск», чтобы твой робот мог
   распознавать голос и смотреть на фото еды.
3. Впишешь оба этих секрета в один файл.
4. Запустишь одну команду — и робот заработает.

---

## Шаг 1. Установи Python

Python — это программа, на которой написан бот.

- Заходишь на https://www.python.org/downloads/
- Нажимаешь большую жёлтую кнопку «Download Python»
- Открываешь скачанный файл и жмёшь «Install» / «Установить»
- **Важно (Windows):** на первом экране установки поставь галочку
  «Add Python to PATH», потом жми «Install Now»

Проверка: открой терминал (см. Шаг 2) и напиши:

```bash
python3 --version
```

Если видишь что-то вроде `Python 3.11.5` — всё получилось.

---

## Шаг 2. Открой терминал

- **Windows:** нажми Win, напиши «PowerShell», открой его
- **Mac:** нажми Cmd+Пробел, напиши «Terminal», открой его
- **Linux:** обычно Ctrl+Alt+T

Дальше все команды набираешь именно в этом чёрном/белом окошке и жмёшь Enter.

---

## Шаг 3. Перейди в папку с ботом

```bash
cd telegram-assistant-bot
```

(Если бот в другом месте — сначала перейди в ту папку, где лежит эта
инструкция.)

---

## Шаг 4. Создай своего бота в Telegram

1. Открой Telegram, найди в поиске **@BotFather**
2. Напиши ему `/newbot`
3. Придумай имя боту (например: `Мой личный помощник`)
4. Придумай username, обязательно заканчивающийся на `bot`
   (например: `ivan_assistant_bot`)
5. BotFather пришлёт тебе длинную строку — токен, например:
   `123456789:AAExampleToken-Do-Not-Share`

   **Это как пароль. Никому его не показывай и никуда не выкладывай.**
   Сохрани его — пригодится на шаге 7.

6. Узнай свой личный Telegram ID: найди в Telegram бота **@userinfobot**,
   напиши ему что угодно — он пришлёт в ответ твой `Id: 123456789`.
   Сохрани и это число — это нужно, чтобы бот отвечал ТОЛЬКО тебе, а не
   всем подряд.

---

## Шаг 5. Получи ключ OpenAI

Он нужен, чтобы бот умел:
- превращать голосовые сообщения в текст (для идей и календаря)
- смотреть на фото еды и считать калории

1. Зайди на https://platform.openai.com/api-keys
2. Зарегистрируйся / войди
3. Нажми «Create new secret key»
4. Скопируй ключ (он показывается только один раз!) — выглядит как
   `sk-...........`
5. На этом же сайте пополни баланс на пару долларов
   (Settings → Billing) — без этого ключ работать не будет.

---

## Шаг 6. Установи всё, что нужно боту

В терминале, находясь в папке `telegram-assistant-bot`, набери по очереди:

```bash
python3 -m venv .venv
```

Это создаёт «отдельную коробочку» для бота, чтобы он не мешал остальным
программам на компьютере.

Дальше — активируй эту «коробочку»:

- **Mac/Linux:**
  ```bash
  source .venv/bin/activate
  ```
- **Windows (PowerShell):**
  ```bash
  .venv\Scripts\Activate.ps1
  ```

Ты поймёшь, что получилось — в начале строки терминала появится `(.venv)`.

Теперь ставим все нужные программы одной командой:

```bash
pip install -r requirements.txt
```

Подожди немного, пока всё скачается.

---

## Шаг 7. Впиши свои секреты

1. Скопируй файл `env.sample` в новый файл с именем `.env`:

   - **Mac/Linux:** `cp env.sample .env`
   - **Windows:** `copy env.sample .env`

2. Открой файл `.env` любым текстовым редактором (Блокнот подойдёт) и
   впиши свои значения после знака `=` (без пробелов и без кавычек):

   ```
   TELEGRAM_BOT_TOKEN=твой_токен_из_шага_4
   ALLOWED_USER_ID=твой_id_из_шага_4
   OPENAI_API_KEY=твой_ключ_из_шага_5
   ```

3. Сохрани файл.

---

## Шаг 8. Запусти бота!

```bash
python3 src/bot/main.py
```

Если всё правильно, ты увидишь в терминале что-то вроде:

```
Бот запускается...
```

И терминал «зависнет» — это нормально, значит бот работает и ждёт
сообщений. Не закрывай это окно, пока хочешь пользоваться ботом.

Теперь открой Telegram, найди своего бота (по username из шага 4) и
напиши `/start`.

---

## Как этим пользоваться

- 🎙 **Идея:** просто запиши голосовое сообщение в любой момент (или
  напиши текстом) — бот сам всё сохранит. Это режим «по умолчанию»,
  ничего нажимать не нужно.
- 📸 **Калории:** нажми кнопку «📸 Калории», потом пришли фото еды.
- ⚖️ **Вес:** нажми «⚖️ Вес», потом напиши число, например `82.4`.
- 💰 **Финансы:** нажми «💰 Финансы», выбери категорию (или «Доход»),
  потом напиши сумму, можно с комментарием: `1500 такси`.
- 📅 **Календарь:** нажми «📅 Календарь» → «➕ Добавить событие» и скажи
  голосом или напиши: «завтра встреча в 14:00 с Ивановым». Кнопки
  «Сегодня» / «Неделя» покажут список событий.
- 📊 **Отчёт:** нажми «📊 Отчёт», выбери месяц — покажет сумму по
  категориям, доход, расход и остаток.

---

## Как остановить бота

Вернись в окно терминала, где он запущен, и нажми `Ctrl+C`.

## Как запустить бота в следующий раз

Каждый следующий раз достаточно двух команд из папки `telegram-assistant-bot`:

```bash
source .venv/bin/activate   # Windows: .venv\Scripts\Activate.ps1
python3 src/bot/main.py
```

Токен и ключ уже сохранены в `.env` — вводить их заново не нужно.

---

## Если что-то не работает

- **«command not found: python3»** — Python не установился или не
  добавлен в PATH. Переустанови (Шаг 1), на Windows не забудь галочку
  «Add Python to PATH».
- **Бот в Telegram не отвечает** — проверь, что окно терминала с ботом
  всё ещё открыто и не показывает ошибку красным текстом.
- **«В файле .env не заполнены обязательные переменные»** — открой
  `.env` и проверь, что все три строки заполнены (без пробелов вокруг
  `=` и без пустых строк).
- **Бот не отвечает вообще ни на что** — проверь `ALLOWED_USER_ID`: это
  должен быть именно твой ID (Шаг 4), не username и не токен бота.
- **Не считает калории / не распознаёт голос** — скорее всего, кончился
  баланс на OpenAI. Проверь на https://platform.openai.com/usage.

---

## Важно про приватность

- Бот отвечает только тебе (по `ALLOWED_USER_ID`) — остальным он
  вежливо откажет.
- Все твои идеи, вес, финансы и события хранятся в одном файле на твоём
  компьютере (`telegram-assistant-bot/data/bot.db`), никуда не
  отправляются, кроме двух исключений: голос и фото еды на короткое
  время уходят в OpenAI, чтобы их распознать (так работают эти функции),
  и не сохраняются на стороне OpenAI дольше, чем нужно для ответа.
- Никогда не выкладывай файл `.env` и не отправляй токен/ключ никому.
