# Личный Telegram-помощник

Приватный Telegram-бот для одного пользователя: захват идей голосом,
подсчёт калорий по фото, учёт финансов по категориям и календарь событий.

**Как запустить:** смотри [docs/SETUP_GUIDE_RU.md](docs/SETUP_GUIDE_RU.md)
— пошаговая инструкция максимально простыми словами.

## Возможности

- 💡 **Идеи** — режим по умолчанию: голосовое или текстовое сообщение в
  любой момент сохраняется как идея (голос распознаётся через OpenAI
  Whisper).
- 📸 **Калории** — фото еды → оценка калорий и БЖУ через OpenAI Vision,
  плюс дневной итог.
- ⚖️ **Вес** — быстрый лог веса с разницей от предыдущего замера.
- 💰 **Финансы** — 8 категорий расходов + доход, ежемесячный отчёт по
  категориям с итогом.
- 📅 **Календарь** — событие голосом/текстом («завтра встреча в 14:00»)
  с автоматическим разбором даты и времени; просмотр на сегодня/неделю.

Бот отвечает только владельцу (`ALLOWED_USER_ID` в `.env`).

## Технологии

- Python 3.11+, [python-telegram-bot](https://github.com/python-telegram-bot/python-telegram-bot) 21 (polling, без сервера/домена)
- SQLite (один файл, без внешней БД) — `src/bot/db.py`
- OpenAI Whisper (голос → текст) и GPT-4o-mini Vision (фото → калории)
- `dateparser`-независимый разбор русских дат/времени (регулярки +
  словари) — `src/bot/services/dateparse.py`

## Структура проекта

```
src/bot/
  main.py            точка входа, сборка Application
  config.py           загрузка .env
  db.py                SQLite: идеи, еда/вес, финансы, календарь
  keyboards.py         постоянное меню + инлайн-кнопки
  states.py             режимы диалога
  handlers/            обработчики команд/кнопок/сообщений
  services/            OpenAI (голос, фото) и разбор дат
tests/                 pytest: БД, разбор дат, финансы, интеграция обработчиков
docs/SETUP_GUIDE_RU.md инструкция по запуску
```

## Тестирование (что проверено, а что нет)

Перед сдачей прогнан весь набор тестов без сети и без реальных
Telegram/OpenAI ключей:

```bash
source .venv/bin/activate
pip install -r requirements-dev.txt
pytest tests/ -q
# 25 passed
```

Покрыто тестами: работа с БД (идеи, еда, вес, финансы, календарь),
разбор русских дат/времени на реальных фразах, разбор суммы+комментария
для финансов, разбор ответа Vision-модели, а также сквозной прогон
обработчиков (`router.on_text`, финансовый флоу, форматирование отчёта и
календаря) на поддельных Update/Context — без обращения к сети.
Дополнительно проверена сборка `Application` (регистрация всех
обработчиков) — `bot/main.py` собирается и не падает.

**Не проверено** (невозможно без реального токена и живого чата):
живой обмен сообщениями с настоящим Telegram-ботом, реальные вызовы
OpenAI (транскрипция голоса, распознавание фото). Логика вокруг этих
вызовов протестирована, сами сетевые вызовы — нет. После первого
запуска (Шаг 8 инструкции) стоит пройтись по всем пунктам меню вручную.

## Быстрый старт (кратко)

```bash
cd telegram-assistant-bot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp env.sample .env   # и впиши туда свои токены
python3 src/bot/main.py
```

Подробности и объяснение каждого шага — в
[docs/SETUP_GUIDE_RU.md](docs/SETUP_GUIDE_RU.md).
